# 任务7：关键词匹配分类 + 清理不准确分类

## 工作记录

1. 构建了包含190个关键词的字典，按关键词长度降序排序，优先匹配更具体的关键词
2. 对输入数据的法条(legal_articles)进行关键词匹配，匹配成功后覆盖原AI分类(legal_violation_categories)
3. 匹配成功的条目在before_legal_categories字段标记(匹配)前缀，保留原分类便于追溯
4. 实现特定法条分类覆盖规则(6-4)，对如《公司法》第二百零一条等特定法条进行硬编码覆盖
5. 实现泛型法条删除规则(6-5)，移除包含"行政处罚程序"、"年度报告"、"行政处罚自由裁量权"等模式的法条，关键词匹配成功的条目豁免此规则
6. 实现星号分类删除规则(6-6)，移除分类中含星号的条目（表示AI分类不确定）
7. 实现泛型+具体分类删除规则(6-7)，移除标记为泛类型但被AI分为具体分类的条目
8. 实现无书名号删除规则(6-8)，移除法条中不含《》或<>等书名号的条目
9. 实现无效结尾删除规则(6-9)，移除法条结尾不符合有效模式（条/款/项/规定等）的条目
10. 输出清洗后词典(任务7_清洗后词典.csv)和删除条目追溯文件(任务7_删除条目.csv)
11. 原始数据36,402条，关键词匹配命中15,525条，最终保留29,125条

## 输入输出

| 文件 | 说明 |
|-----|-----|
| `任务6_分类已修正.csv` | 输入 |
| `任务7_清洗后词典.csv` | 输出：清洗后词典 |
| `任务7_删除条目.csv` | 输出：删除条目及原因 |
| `任务7_中间_关键词匹配.csv` | 中间结果 |
