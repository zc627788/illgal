# 任务8：法条格式清洗 + 去重

## 工作记录

1. 分析了29,125条法条的开头和结尾字符分布，确定有效格式规则
2. 实现前缀清理功能，去除"依据"、"根据"、"参照"、"按照"、"依照"等无意义前缀
3. 实现后缀截断功能，找到最后一个有效法条编号位置（条/款/项/规定/》等），截断后面的多余内容
4. 处理了"第X条和国家工商局"、"第一款的规定对你公司作出罚款"等尾部杂乱内容
5. 保留多法条引用格式如"第二十条和第二十五条的规定"，保留括号项号如"第五条第（二）项"
6. 实现基于legal_articles列的去重功能，保留第一条重复记录
7. 输出清洗去重后词典(任务8_清洗去重后词典.csv)、修改记录(任务8_修改记录.csv)、重复记录(任务8_重复记录.csv)
8. 原始29,125条，清洗修改5,174条，去重删除4,948条，最终保留24,177条

## 输入输出

| 文件 | 说明 |
|-----|-----|
| `任务7_清洗后词典.csv` | 输入 |
| `任务8_清洗去重后词典.csv` | 输出：最终词典 |
| `任务8_修改记录.csv` | 输出：修改记录 |
| `任务8_重复记录.csv` | 输出：重复记录 |

python clean_article_edges.py
